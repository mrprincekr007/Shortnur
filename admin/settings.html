Ad System

Visitors pass through countdown ad pages before reaching the destination. Har box ke aage AdTrader unit name likha hai — wahi code us box me daalo, aur Preview se dekh sakte ho kahan dikhega.

Countdown & Earning
Visitor ad pe kitne second tak rahega. Jitna zyada, utna ad dikhna (earning badhne ka mauka).
User ko sirf Countdown Timer (upar wala) dikhega, par Continue button itne extra second baad active hoga. Example: Timer 15 + Fake 10 = user 15s dekhta hai, asli wait 25s.
Har link khulte hi kitni ad pages dikhein (har page pe timer + ad). Jitni zyada pages, utni zyada earning.
1000 completed views pe user ko kitna (CPM). $10 = 1000 views pe $10. Ye ad earnings se chhota hona chahiye.
