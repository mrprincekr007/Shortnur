Ad System

Visitors pass through countdown ad pages before reaching the destination. Har ad ka apna box hai — niche samjha hai kaunsa ad kya karta hai.

Countdown & Earning
Visitor ad pe kitne second tak rahega. Jitna zyada, utna ad dikhna (earning badhne ka mauka).
Har link khulte hi kitni ad pages dikhein (har page pe timer + ad). Jitni zyada pages, utni zyada earning.
1000 completed views pe user ko kitna (CPM). $10 = 1000 views pe $10. Ye ad earnings se chhota hona chahiye.
1. Main Ad — Multitag / Banner

Ye ad countdown page ke upar bade box me dikhta hai. Adsterra Multitag ya kisi bhi network ka banner code yahan paste karo. (Multitag me Vignette / In-Page Push / Banner sab isi code se aate hain.)

Agar upar HTML code hai toh ye khaali chhodo. Sirf tab use karo jab iframe URL ho.
1b. Second Ad — Bottom Box (optional)

Ye ad timer ke neeche second bade box me dikhta hai. Iske liye Adsterra me alag Display Banner zone banao (duplicate zone na ho toh better). Agar chhodo toh second box nahi dikhega.

Agar upar HTML code hai toh ye khaali chhodo.
2. OnClick Popunder

Visitor pehli baar click kare toh popunder naye tab me khulega (aur page scroll unlock hoga). Adsterra dashboard me OnClick (Popunder) zone bana ke uska code yahan daalo.

Agar code hai toh ye khaali chhodo. URL only tab use karo jab code na ho.

Admin Access

Admin access is configured in firebase/firebase-config.js (ADMIN_UIDS array). Add your Firebase UID there to grant access.

Danger Zone

These actions are irreversible. Be careful.
